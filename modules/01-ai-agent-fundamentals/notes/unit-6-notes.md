## Question 1

**Which of the following best describes an AI agent?**

| Option | Answer |
|--------|--------|
| A | A developer who specializes in building generative AI solutions |
| B | A software service that uses AI to assist users with information and task automation |
| C | A marketplace for off-the-shelf AI software components |

✅ **Correct answer: B**

> An AI agent is a software service that uses AI to assist users with information and task automation. It reasons, acts, and remembers — not just a chatbot, not a marketplace, not a person.

## Question 2

**Which AI agent development service offers a choice of generative AI models from multiple vendors in the Microsoft Foundry model catalog?**

| Option | Answer |
|--------|--------|
| A | Microsoft Foundry Agent Service |
| B | OpenAI Assistants API |
| C | Microsoft 365 Copilot Chat |

✅ **Correct answer: A**

> Foundry Agent Service provides access to the Foundry model catalog with models from multiple vendors. OpenAI Assistants API is limited to OpenAI models only.

## Question 3

**What element of a Foundry Agent Service agent enables it to *ground* prompts with contextual data?**

| Option | Answer |
|--------|--------|
| A | Model |
| B | Code interpreter tool |
| C | Knowledge |

✅ **Correct answer: C**

> Knowledge (data sources like Azure AI Search, web search, SharePoint, Blob storage) enables grounding. The model reasons over the grounded prompt; knowledge provides the context.
