## Key takeaways (fill in as you go)

- **What makes an agent:** plan, use tools, perceive, remember
- **Agent vs RAG vs Copilot vs Workflow:** agents add a reasoning loop
- **Development spectrum:** single model call → prompt agent → hosted agent
- **Foundry Agent Service:** managed platform for prompt agents and hosted agents
